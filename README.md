# StayFind 🏠

StayFind is a student accommodation finder that helps students find affordable and comfortable accommodation close to campus.

## Features

- User registration and login
- Firebase Authentication
- Browse available student properties
- Search properties by location
- Filter properties by maximum price and number of rooms
- View complete property details
- Contact landlords through email
- Add new properties
- Edit existing properties
- Delete properties with confirmation
- User dashboard for managing listed properties
- Responsive design for desktop, tablet and mobile
- Firestore security rules for property management

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Font Awesome

## How It Works

Users can browse and search available accommodation without creating an account.

Registered users can log in to their dashboard where they can add, edit and delete their own property listings.

Property information is stored and retrieved dynamically using Cloud Firestore.

## Project Purpose

StayFind was developed as a student accommodation web application project to demonstrate frontend development, Firebase authentication, database integration and responsive web design.
